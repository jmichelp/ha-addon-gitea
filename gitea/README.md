## About

This add-on allows you to run a lightweight, self-hosted Gitea Git service directly within Home Assistant.

## Features

- Home Assistant Ingress integration (sidebar access)
- Built-in Git SSH daemon on port 3022
- SQLite database out of the box
- SSL/TLS and NGINX Proxy support
- Git LFS support
- AppArmor protected and rootless execution
